# Kasa

Chez vous, partout et ailleurs

## Description

Kasa est une application React développée pour afficher des annonces de logements. Elle inclut des composants React et les routes de React Router. Les maquettes Figma ont été respectées et un fichier JSON est utilisé pour les données des logements. L'application est entièrement responsive.

## Technologies utilisées

- React
- HTML
- CSS

## Fonctionnalités

- Affichage des annonces de logements
- Affichage des détails de chaque logement
- Navigation avec React Router
- Application responsive design
- Utilisation des maquettes Figma pour le design
- Données de logements stockées dans un fichier JSON
